Use the common session-control skill. Use the account's authorized custom tool/plugin path only when the actual product surface supports the required write tool. The built endpoint uses per-client bearer credentials, not OAuth. An OAuth-only client requires a separately reviewed gateway that validates user/client/scopes and securely maps them to the internal credential; do not simply forward arbitrary bearer values. An authorized computer can use the same `psr` CLI. The package does not bypass platform write permissions or pretend a read tool can submit work.
